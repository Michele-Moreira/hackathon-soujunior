# Hackathon SouJunior

Projeto do time para o hackathon da SouJunior.

## Stack

Vite + React + TypeScript + Tailwind CSS + shadcn/ui. Deploy na Vercel.

## Rodando local

```bash
npm install
npm run dev
```

| Comando | O que faz |
|---|---|
| `npm run dev` | sobe o servidor local |
| `npm run build` | checa os tipos e gera a versão de produção em `dist/` |
| `npm run lint` | roda o oxlint |
| `npx shadcn@latest add <componente>` | adiciona um componente do shadcn em `src/components/ui/` |
